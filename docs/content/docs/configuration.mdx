gdhealth reads its configuration from `gdhealth.toml` at the project root (or from the path given by `--config`). If no config file is found, built-in defaults are used — you can run gdhealth without any config file.

## `[project]`

Optional. Rarely needed since `--root` overrides this at runtime.

| Field | Type | Default | Description |
|---|---|---|---|
| `root` | string | `"."` | Project root path. Overridden by `--root` flag. |

---

## `[discovery]`

Controls which files are discovered and analyzed.

| Field | Type | Default | Description |
|---|---|---|---|
| `include` | string[] | `["**/*.gd"]` | Glob patterns for files to include |
| `exclude` | string[] | `["addons/**", ".godot/**", "reports/**"]` | Glob patterns for files to exclude |

Patterns prefixed with `!` inside an `include` list act as negations. Patterns are matched against project-relative paths.

---

## `[groups]`

Named groups assign files to logical layers. Each key is a group name; the value is a list of glob patterns.

```toml
[groups]
gameplay = ["*.gd", "!server/**", "!net/**"]
net      = ["net/**"]
server   = ["server/**"]
```

Files not matched by any group are labelled **ungrouped** in reports. Groups are referenced by name in `[policy]` forbidden dependency rules.

If no groups are defined, all files are ungrouped and no forbidden dependency rules can fire.

---

## `[thresholds]`

Complexity thresholds that drive policy findings. Each metric has a `_warn` and `_critical` pair — findings below warn are ignored, findings between warn and critical get severity `warning`, findings at or above critical get severity `critical`.

The `warn` threshold must be ≤ the `critical` threshold or config validation fails.

| Field | Type | Default |
|---|---|---|
| `file_lines_warn` | int | 500 |
| `file_lines_critical` | int | 1000 |
| `function_lines_warn` | int | 40 |
| `function_lines_critical` | int | 80 |
| `cyclomatic_warn` | int | 10 |
| `cyclomatic_critical` | int | 15 |
| `nesting_warn` | int | 4 |
| `nesting_critical` | int | 6 |
| `parameters_warn` | int | 5 |

`parameters_warn` has no `_critical` counterpart — parameter count findings are always `warning`.

## `[policy]`

### `allow_cycles`

Dependency cycles whose files all match at least one of these glob patterns are suppressed (not emitted as findings).

```toml
[policy]
allow_cycles = ["test/**", "tools/**"]
```

Leave empty to report all cycles.

### `[[policy.forbidden_dependencies]]`

Each entry defines a forbidden dependency rule. If a file in group `from` depends on a file in group `to`, a finding with the given severity is emitted.

```toml
[[policy.forbidden_dependencies]]
from     = "server"
to       = "gameplay"
severity = "critical"
```

| Field | Type | Values |
|---|---|---|
| `from` | string | Group name defined in `[groups]` |
| `to` | string | Group name defined in `[groups]` |
| `severity` | string | `info`, `warning`, `critical` |

Multiple rules are allowed. Each is independent — all matching rules fire for a given edge.

## `[git]`

Controls the git-derived signals (churn hotspots, ownership, co-change, change entropy,
prior-defect history) computed by `gdhealth health`, `gdhealth risk`, and `gdhealth validate-defects`.
Shells out to the system `git` binary — no `git2`/libgit2 dependency. Experimental (see
[Schema Reference](/docs/schema-reference)).

| Field | Type | Default | Description |
|---|---|---|---|
| `enabled` | bool | `true` | Set `false` to skip git entirely (same effect as `--no-git`) |
| `blame_max_file_lines` | int | 2000 | Skip `git blame` on files larger than this, to bound cost |
| `hotspot_halflife_days` | float | 60 | Decay half-life for the temporal hotspot score |
| `co_change_window_days` | float | 90 | Decay time constant for co-change weight and change entropy |
| `co_change_max_files_per_commit` | int | 20 | Commits touching more files than this are excluded as mass-edit noise |
| `prior_defect_window_days` | int | 180 | Trailing window for counting fix-shaped commits per file |

If the project root isn't a git repository (or `git` isn't installed), gdhealth degrades gracefully —
`git_available: false` in `health.json`, no other command fails.

---

## `[refactoring]`

Bounds for the Break Cycle and Split File refactoring suggestions attached to policy findings.

| Field | Type | Default | Description |
|---|---|---|---|
| `max_cycle_files` | int | 8 | Skip Break Cycle on cycles larger than this |
| `max_cut_edges` | int | 2 | Try removing up to this many edges to break a cycle (capped at 2 regardless of a higher value) |
| `split_file_min_symbols` | int | 4 | Minimum top-level symbols before Split File is attempted |
| `split_file_modularity_gate` | float | 0.3 | Minimum modularity for a Split File suggestion to fire |

---

## `[duplication]`

Token-kind clone detection (Rabin-Karp rolling hash). Identifiers collapse to a single token kind,
so a copy-pasted block with renamed variables still matches.

| Field | Type | Default | Description |
|---|---|---|---|
| `enabled` | bool | `true` | Set `false` to skip duplication detection |
| `min_token_window` | int | 150 | Minimum matching token window. Lower values catch smaller clones but produce more noise — 40 was tried and found too short in practice (idiomatic GDScript field/export boilerplate matched across unrelated files). |
