## Download a release binary

Each [GitHub release](https://github.com/q-rault/gdhealth/releases) has a
binary for each platform, no Rust needed:

| Platform | Archive |
| --- | --- |
| macOS arm64 | `gdhealth-*-aarch64-apple-darwin.tar.gz` |
| macOS x86_64 | `gdhealth-*-x86_64-apple-darwin.tar.gz` |
| Linux x86_64 | `gdhealth-*-x86_64-unknown-linux-musl.tar.gz` |
| Windows x86_64 | `gdhealth-*-x86_64-pc-windows-msvc.zip` |

Put the `gdhealth` binary on your `PATH`. With [gdsuite](https://github.com/q-rault/gdsuite),
`gdsuite setup` downloads the version it was tested with for you.

## Install from crates.io

Requires Rust 1.96 or later (`rustup update stable` to upgrade).

```sh
cargo install gdhealth
```

## Install from source

From the repository root:

```sh
cargo install --path .
```

This compiles and installs the `gdhealth` binary into `~/.cargo/bin/`, which should already be on your `PATH` if you've used Cargo before.

Use `--force` to replace an existing installation:

```sh
cargo install --path . --force
```

## Build without installing

If you only want the binary for local use:

```sh
cargo build --release
```

The binary is at `target/release/gdhealth`.

## Verify the installation

```sh
gdhealth --help
```

You should see the command overview and list of subcommands.
