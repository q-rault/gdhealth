## Requirements

- Rust 1.85 or later (`rustup update stable` to upgrade)

## Install from source

From the repository root:

```sh
cargo install --path .
```

This compiles and installs the `gdhealth` binary into `~/.cargo/bin/`, which should already be on your `PATH` if you've used Cargo before.

Use `--force` to replace an existing installation:

```sh
cargo install --path . --force
```

## Build without installing

If you only want the binary for local use:

```sh
cargo build --release
```

The binary is at `target/release/gdhealth`.

## Verify the installation

```sh
gdhealth --help
```

You should see the command overview and list of subcommands.
